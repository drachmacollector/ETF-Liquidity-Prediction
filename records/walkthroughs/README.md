# Phase Walkthroughs

One file per phase, `PXX_walkthrough.md`, written from [`docs/process/templates/WALKTHROUGH_TEMPLATE.md`](../../docs/process/templates/WALKTHROUGH_TEMPLATE.md) at the end of the phase (with dated checkpoint sections for long phases).

A walkthrough records what **actually** happened: what was completed, decisions, deviations from the plan, findings, issues, unresolved problems, the exact current state, how to reproduce, and the handoff to the next phase. A fresh agent should be able to continue the project from the latest walkthrough plus `records/STATUS.md` without reading the code.
